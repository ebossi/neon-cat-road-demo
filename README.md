# Neon Cat Road — web demo

Playable HTML5 (Unity Web) build of **Neon Cat Road** (*Spin & Connect Puzzle*). Build output only; the game source lives elsewhere.

- Play: https://ebossi.github.io/neon-cat-road-demo/
- With simulated ads and payments: https://ebossi.github.io/neon-cat-road-demo/?mockads=1&mockiap=1

Best on a phone in portrait. Progress is saved in the browser (localStorage).
